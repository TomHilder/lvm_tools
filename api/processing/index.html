    Processing API¶

    The functions behind DataConfig.from_tiles and FitDataBuilder.build: clipping to wavelength and sky ranges, setting bad data to NaN, and normalisation. Use them directly to inspect intermediate steps, e.g. filter_inspector to see how much data each filter removes.

    Pipeline functions¶

    These apply a DataConfig to tiles. FitDataBuilder.build runs process_tile_data, then flatten_tile_coord, then get_normalisation_functions.

    lvm_tools.fit_data.processing.flatten_tile_coord(ds) ¶

    Flatten the tile and spaxel dimensions into a single flat_spaxel dimension.

    flat_spaxel runs over the spaxels of the first tile, then the second, and so on. It is placed last, so the cubes have dimensions (wavelength, flat_spaxel). The tile and spaxel values of each flat spaxel are kept as coordinates along it, and per-tile coordinates such as mjd are repeated for each spaxel.

    Parameters:

    Name Type Description Default
    ds Dataset

    Data with tile and spaxel dimensions.

    		 required

    Returns:

    Type Description
    Dataset

    The flattened data.

    Clipping functions¶

    lvm_tools.fit_data.clipping.clip_dataset(data, λ_range, α_range, δ_range) ¶

    Clip tile data to wavelength range(s) and an RA/Dec box.

    The wavelengths are clipped with clip_wavelengths. Values at spaxels outside the RA/Dec box (bounds included) are set to NaN, and spaxels that are outside it in every tile are dropped.

    Wavelength range(s) to keep, in Angstrom.

    		 required
    α_range Range

    		 required
    δ_range Range

    Declination range (min, max) to keep, in degrees.

    		 required

    Raises:

    Filtering functions¶

    lvm_tools.fit_data.filtering.filter_dataset(data, nans_strategy, F_bad_strategy, F_bad_range, fibre_status_include, apply_mask) ¶

    Set bad data to NaN.

    A value is excluded if any of these flag it: the NaN strategy, the bad flux strategy, the fibre status, and (if apply_mask) the DRP mask. All data variables (flux, inverse variance, LSF and mask) are set to NaN where excluded; spaxel-level flags exclude every wavelength of the spaxel.

    Parameters:

    Name Type Description Default
    data Dataset

    Tile data, as in LVMTile.data.

    		 required
    nans_strategy ExcludeStrategy

    "pixel" (keep other pixels of a spaxel with NaN fluxes) or "spaxel" (exclude spaxels with any NaN flux).

    		 required
    F_bad_strategy ExcludeStrategy

    "pixel", "spaxel" or "spaxel_max"; see DataConfig.F_bad_strategy.

    		 required
    F_bad_range tuple[float, float]

    The acceptable flux range (min, max).

    		 required
    fibre_status_include tuple[FibreStatus]

    Fibre status values to keep.

    		 required
    apply_mask bool

    Whether to exclude the pixels flagged in the DRP mask.

    		 required

    Returns:

    Type Description
    Dataset

    The data, with excluded values set to NaN.

    Raises:

    Type Description
    ValueError

    If nans_strategy or F_bad_strategy is not one of the values above.

    lvm_tools.fit_data.filtering.filter_inspector(data, F_bad_range, fibre_status_include) ¶

    Count how many pixels and spaxels each filter would exclude, to help choose a config.

    Each entry of the result is a pair (n_pixels, n_spaxels), with None where a count doesn't apply:

    • "nans": NaN fluxes, and spaxels with any NaN flux.
    • "bad flux": pixels flagged by get_where_bad (the "pixel" strategy).
    • "bad flux median": spaxels flagged by get_where_bad_median (the "spaxel" strategy).
    • "fibre status": spaxels whose fibre status is not in fibre_status_include.
    • "mask": pixels flagged in the DRP mask, and spaxels with any flagged pixel.
    • "any bad": pixels flagged by any of NaN, bad flux, fibre status or mask, and spaxels with any pixel flagged by NaN, bad median flux, fibre status or mask.

    Parameters:

    Name Type Description Default
    data Dataset

    Tile data, as in LVMTile.data.

    		 required
    F_bad_range tuple[float, float]

    The acceptable flux range (min, max).

    		 required
    fibre_status_include tuple[FibreStatus]

    Fibre status values to keep.

    		 required

    Returns:

    Type Description
    dict

    The counts, keyed by filter name.
    Example 
    stats = filter_inspector(tile.data, (-1e-14, np.inf), (0,))
print(f"NaN pixels: {stats['nans'][0]}")
print(f"Bad fibre spaxels: {stats['fibre status'][1]}")

    Normalisation functions¶

    lvm_tools.fit_data.normalisation.calc_normalisation(data, strategy) ¶

    The offset and scale that normalise data as (data - offset) / scale.

    NaN values are ignored. The strategies give:

    Strategy Offset Scale
    None 0 1
    "max only" 0 maximum
    "98 only" 0 98th percentile
    "extrema" minimum maximum - minimum
    "1σ" mean 2 × standard deviation
    "2σ" mean 4 × standard deviation
    "3σ" mean 6 × standard deviation
    "padded" minimum - 0.15 × range 1.3 × range

    So "extrema" maps the data onto [0, 1], "Nσ" maps mean ± Nσ onto an interval of width 1 centred on 0, and "padded" maps the data onto [0.15/1.3, 1.15/1.3], leaving NORM_PADDING of the range free on each side.

    Parameters:

    Name Type Description Default
    data ArrayLike

    The values.

    		 required
    strategy NormaliseStrategy

    The normalisation strategy.

    		 required

    Returns:

    Type Description
    tuple[float, float]

    The pair (offset, scale).

    Raises:

    Type Description
    ValueError

    If the strategy is unknown.
