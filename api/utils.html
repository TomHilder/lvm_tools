Utilities API#

This module provides utility functions for physical calculations and spatial operations.

Barycentric Corrections#

lvm_tools.physical_properties.barycentric_corr.get_v_barycentric(mjd, α, δ, unit='km/s')#

Compute barycentric velocity correction.

Uses the Las Campanas Observatory location and the astropy radial velocity correction framework.

Parameters:

  • mjd (ArrayLike) – Modified Julian Date(s)

  • α (ArrayLike) – Right ascension in degrees

  • δ (ArrayLike) – Declination in degrees

  • unit (str) – Output unit (default “km/s”)

Returns:

Barycentric velocity correction

Return type:

numpy.ndarray

Example:

from lvm_tools.physical_properties.barycentric_corr import get_v_barycentric
import numpy as np

# Single observation
v_bary = get_v_barycentric(
    mjd=60000.5,
    α=180.0,
    δ=-30.0,
)
print(f"v_bary = {v_bary:.2f} km/s")

# Multiple observations
v_bary = get_v_barycentric(
    mjd=np.array([60000.5, 60001.5]),
    α=np.array([180.0, 180.1]),
    δ=np.array([-30.0, -30.1]),
)

Spatial Masking#

lvm_tools.utils.mask.mask_near_points(xgrid, ygrid, xpoints, ypoints, threshold=None)#

Generate a boolean mask for grid cells near data points.

Uses a KD-tree for efficient nearest-neighbour lookup.

Parameters:

  • xgrid (numpy.ndarray) – Grid coordinates along x-axis (monotonically increasing)

  • ygrid (numpy.ndarray) – Grid coordinates along y-axis (monotonically increasing)

  • xpoints (numpy.ndarray) – X-coordinates of data points

  • ypoints (numpy.ndarray) – Y-coordinates of data points

  • threshold (float | None) – Maximum distance to be considered “near”. If None, uses 1.5 times the maximum of mean grid spacings

Returns:

Boolean mask, shape (len(ygrid), len(xgrid)), True means “keep”

Return type:

numpy.ndarray

Example:

import numpy as np
from lvm_tools.utils.mask import mask_near_points

# Create a regular grid
xgrid = np.linspace(0, 10, 100)
ygrid = np.linspace(0, 10, 100)

# Scattered data points
xpoints = np.random.uniform(2, 8, 50)
ypoints = np.random.uniform(2, 8, 50)

# Generate mask
mask = mask_near_points(xgrid, ygrid, xpoints, ypoints)

# Apply to a 2D array
data = np.ones((len(ygrid), len(xgrid)))
masked_data = np.where(mask, data, np.nan)

Use Case:

This function is useful for creating masks that restrict model evaluation to regions with data coverage, avoiding extrapolation in sparse regions.

Helper Functions#

Array Conversion#

lvm_tools.data.helper.daskify_native(array, chunks)

Convert an array to a Dask array with native byte order.

The array (typically a FITS memmap) is read lazily: computing a slice reads and byte-swaps only the chunks it touches, not the whole array.

Handles FITS files which may store data in non-native byte order.

Parameters:

  • array (ArrayLike) – Input array

  • chunks (str | int | tuple) – Dask chunk specification

Returns:

Dask array

Return type:

dask.array.Array

lvm_tools.data.helper.numpyfy_native(array)

Convert an array to NumPy with native byte order.

Parameters:

array (ArrayLike) – Input array

Returns:

NumPy array

Return type:

numpy.ndarray

Coordinate Utilities#

lvm_tools.data.coordinates.get_mjd(header)

Extract observation midpoint MJD from FITS header.

Uses INTSTART and INTEND keywords to compute the midpoint.

Parameters:

header (astropy.io.fits.Header) – FITS primary header

Returns:

Modified Julian Date

Return type:

float

Raises:

ValueError – If time keywords are missing

lvm_tools.data.coordinates.get_observatory_code(header)#

Extract observatory code from FITS header.

Parameters:

header (astropy.io.fits.Header) – FITS primary header

Returns:

Observatory code (e.g., “LCO”)

Return type:

str

Raises:

ValueError – If observatory is unknown

lvm_tools.data.coordinates.get_observatory_location(observatory)

Get Earth location for a named observatory.

Parameters:

observatory (str) – Observatory code

Returns:

Observatory location

Return type:

astropy.coordinates.EarthLocation

Raises:

ValueError – If observatory is unknown

Currently supported: “LCO” (Las Campanas Observatory)
